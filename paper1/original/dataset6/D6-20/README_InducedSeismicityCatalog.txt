Illinois State Geological Survey (ISGS), Illinois Basin - Decatur Project (IBDP) Induced microseismicity event catalog, June 28, 2021. Midwest Geological Sequestration Consortium (MGSC) Phase III Data Sets. DOE Cooperative Agreement No. DE-FC26-05NT42588.

The events in the catalog were recorded after the start of injection on 17 November 2011 until 2 July 2018 (2 years and 5 months after CCS1 injection ended). The event locations are provided in State Plane Coordinate System, Illinois East 1201, NAD27 

This file contains
- spreadsheet containing all events by data or occurence, located events by date of occurrence, plots of events distributions, trigger change information, sensor information, event azimuth relative to CCS1. 
- tab-delimited text file with .rdv extension containing source parameters
- spreadsheet containing a subset of the located event catalog relocated using the double-difference method described in Dando, B. D. E., B. P. Goertz-Allmann, D. Kühn, N. Langet, A. M. Dichiarante, and V. Oye, 2021, Relocating microseismicity from downhole monitoring of the Decatur CCS site using a modified double-difference algorithm: Geophysical Journal International, v. 227, no. 2, p. 1094–1122, doi:10.1093/GJI/GGAB255.
